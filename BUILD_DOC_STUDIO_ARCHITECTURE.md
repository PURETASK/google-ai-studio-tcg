## 2. THE COMMAND LAYER (STAGE A)

### CMD-01 — Nexus TCG Design Director
- **Role Class**: Command / Orchestration / Governance
- **Authority**: Highest AI operational authority beneath the human Project Owner.
- **Mission**: Coordinates complete game development, enforces review gates, converts informal user ideas into structured investigations, and prevents premature locking.
- **Inputs**: Master Database, Rules Bible, Domain Bibles, Canon Archive, Playtest Logs, Unresolved Questions.
- **Outputs**: Task Plans, Agent Rosters, Dependency Graphs, Conflict Escalations, Decision Briefs.
- **Key Power**: Can block `LOCKED` status for dependency failures, missing validation passes, or unaddressed `N4/N5` Nuance findings.

### CMD-02 — Question Architect
- **Role Class**: Inquiry / Problem Formulation / Assumption Discovery
- **Authority**: Inquiry authority only; cannot lock answers or design independently.
- **Mission**: Discovers unanswered questions, exposes unstated assumptions, detects semantic ambiguity, and builds structured question trees before design work begins.

## 4. AUTHORITY MATRIX & NON-NEGOTIABLES

| Agent Role | Can Block LOCK? | Primary Lock-Blocking Reason |
|---|:---:|---|
| **Project Owner** | ✅ **YES** | Final creative & business authority across all domains |
| **CMD-01 TCG Director** | ✅ **YES** | Process/dependency failure, missing gates, or unresolved blockers |
| **GLO-02 Rules Architect** | ✅ **YES** | Ambiguous foundational rule or conflicting zone procedures |
| **GLO-03 Timing Architect** | ✅ **YES** | Unresolved timing contradiction, infinite loop, or non-deterministic chain |
| **GLO-10 Balance Analyst** | ✅ **YES (Conditional)** | Severe demonstrated mathematical/efficiency failure |
| **GLO-14 Red Team** | ✅ **YES** | Critical exploit, sacrifice loop, or deterministic lockout found |
| **GLO-15 Digital Engine** | ✅ **YES** | Non-deterministic digital state machine behavior |
| **GLO-18 Lore & Canon** | ✅ **YES** | Direct contradiction with established world canon |
| **GLO-19 Data & QA** | ✅ **YES** | Missing provenance, schema mismatch, or version collision |
| **Domain Directors (5)** | ✅ **YES** | Domain authenticity or faction identity violation |
| **GLO-16 Art Style Director**| ✅ **YES** | Visual quality or faction composition violation |
| **Nuance Council (NUA-01..08)**| ✅ **YES (at N4/N5)**| Critical or Systemic nuance finding |
| **CMD-02 Question Architect** | ❌ NO | Inquiry authority only (generates question trees) |
| **GLO-07 Card Designer** | ❌ NO | Proposal authority only |
| **GLO-11 Simulation** | ❌ NO | Evidence provider only |
| **GLO-13 Fun/PX Analyst** | ❌ NO (Alone) | Requires human playtest correlation |

### Non-Negotiable Universal Prohibitions
1. **No Majority Voting**: 7 agents voting YES does not override 1 Red-Team agent who discovered an infinite loop. Evidence and severity outrank consensus.
2. **Anti-Hallucination & Provenance**: Agents may never invent missing canon silently. If historical evidence is missing, it must be marked `UNKNOWN`, `UNRECOVERED`, or `SOURCE-PENDING`.
3. **No Self-Locking**: No agent may mark its own proposal `LOCKED`.
4. **No Silent Overwrites**: Lower source tiers may never overwrite higher source tiers.

## 6. NUANCE SEVERITY SCALE (N0–N5) & ESCALATION LEVELS (E0–E5)

### Nuance Severity Scale
- **N0 (Observation)**: Zero rules or balance implications. Informational log only.
- **N1 (Minor)**: Advisory notice to design team; slight cognitive friction. Safe to proceed.
- **N2 (Meaningful)**: Noticeable interaction ambiguity; review recommended before internal test.
- **N3 (Major)**: Significant potential for degenerate play patterns; revision strongly recommended.
- **N4 (Critical)**: **BLOCKS LOCKING**. Direct rules contradiction, timing deadlock, or infinite loop.
- **N5 (Systemic)**: **BLOCKS ENTIRE AFFECTED SYSTEM**. Global breakdown of turns, resources, or engine.

### Escalation Hierarchy
- **E0**: Single-agent autonomous resolution.
- **E1**: Specialist disagreement (Peer A vs Peer B) resolved by CMD-01 evidence comparison.
- **E2**: Discipline conflict (e.g. Balance vs Domain Director). Both articulate trade-offs.
- **E3**: Multi-system collision (3+ systems affected). Activated Question Architect + Nuance Council.
- **E4**: Foundational decision affecting game identity. Escalated to Project Owner with Decision Brief.
- **E5**: Creative philosophy or lore direction. Supreme decision by Human Project Owner.

## 7. QUESTION-FIRST PROTOCOL & USER IDEA PIPELINE

The studio translates informal human brainstorms into rigorous systems without requiring the user to speak technical TCG jargon:

```text
INFORMAL USER IDEA ("Hazards should feel crazier in late game")
  │
  ▼
INTENT ANALYSIS (Higher tension? Wider radius? Dynamic spectacle?)
  │
  ▼
QUESTION TREE (CMD-02 generates 4-6 foundational questions)
  │
  ▼
ASSUMPTIONS & DEPENDENCIES IDENTIFIED
  │
  ▼
MINIMAL AGENT ROUTING (Activate 3-8 relevant specialists)
  │
  ▼
VALIDATION GATES (Math Balance -> Red-Team Loop Check -> Engine Determinism)
  │
  ▼
NUANCE AUDIT (NUA-01..08 evaluate edge cases & salt factors)
  │
  ▼
CMD-01 DECISION SYNTHESIS BRIEF -> PROJECT OWNER
```
